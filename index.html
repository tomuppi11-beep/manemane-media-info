Manemane Media

Manemane Mediaは、運用者本人の動画制作素材をGoogle Driveへ保存し、編集時にPCへ戻すための個人用ツールです。一般利用者向けの登録サービスは提供していません。

機能

指定した動画・画像・音声ファイルをGoogle Driveへ転送します。ファイルのサイズとハッシュを照合し、保存済み素材を必要に応じてPCへ復元します。PCの容量を確保するため、保管と照合が済んだ古い作業用コピーを削除する機能があります。

プライバシーポリシー

本ツールは、運用者が認証したGoogleアカウントのメールアドレス、Driveの空き容量、指定フォルダ、素材ファイル、およびファイル名・サイズ・ハッシュなどの管理情報へアクセスします。利用目的は素材の保管、整合性の確認、復元、PCの作業用コピーの管理です。

Google Drive APIへの認証にOAuthを使用します。認証情報は運用者のPCに保存します。素材と復元に必要な管理台帳は、運用者が指定したGoogle Driveフォルダに保存します。

本ツールの保管・復元処理は、素材を広告配信、第三者への販売、AIモデルの学習に利用しません。素材を第三者へ公開・共有する機能や、Drive上の素材を自動削除する機能は実装していません。Driveの既存の共有設定は変更しません。Googleとホスティング事業者によるサービス提供時の処理には、それぞれのポリシーが適用されます。

運用者はGoogleアカウントの接続設定から本ツールのアクセスを取り消せます。取り消し後はDriveへの保管と復元ができなくなります。保存済みの素材と管理台帳は、運用者がGoogle DriveまたはPCで削除できます。アクセスの取り消しだけで保存済みファイルは削除されません。

Google APIから取得する情報の使用と他のアプリへの転送は、限定的な使用に関する要件を含むGoogle API Services User Data Policyに従います。

利用案内

本ツールは運用者本人の素材管理に使用します。運用者が保存・編集できるファイルを対象とし、保存先と認証アカウントを確認して使用します。ファイルの公開、転載許可、著作権の判断は本ツールの保管機能に含まれません。

認証失効、通信障害、容量不足、照合不一致の場合は処理を停止して記録します。クラウドへの保管を確認できない素材はPCから自動削除しません。日次処理は設定したPCが利用可能なときに実行します。

問い合わせ先はGoogleのOAuth同意画面に表示するユーザーサポートメールです。
